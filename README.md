# Liquidity Gravity Fields

A public TradingView Pine Script indicator project published by Jayadev Rana for traders and developers studying EMA, SMA, RSI.

## Overview

This repository contains a Pine Script source file saved as `pinescript_liquidity_gravity_fields_indicator.txt` so it opens easily on GitHub and can be copied into TradingView.

The script focuses on EMA, SMA, RSI, ATR, Pivot, volume filter. It is useful for TradingView chart study, Pine Script learning, technical-analysis research, alerts, and strategy development workflows.

For custom TradingView Pine Script development, visit https://jayadevrana.com.

## Indicator Description

Liquidity Gravity Fields gives traders a practical chart workflow around EMA, SMA, RSI, ATR. The source is kept readable in a single `.txt` file so the logic can be reviewed, copied, and adapted inside TradingView.

This project is part of the Jayadev Rana public Pine Script portfolio. The goal is to show real TradingView development examples without making unsupported profit claims. Use it as a research starting point, educational reference, or base for custom Pine Script development.

## How to Use in TradingView

1. Open TradingView.
2. Go to the Pine Editor.
3. Copy the code from `pinescript_liquidity_gravity_fields_indicator.txt`.
4. Paste it into the Pine Editor.
5. Save the script.
6. Add it to your chart.
7. Configure the available inputs.
8. If alert conditions are available, create alerts from TradingView's alert dialog.
